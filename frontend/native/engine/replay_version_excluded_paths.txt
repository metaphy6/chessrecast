# replay_version_excluded_paths.txt
#
# Files under frontend/native/engine/ that are intentionally excluded from
# the ENGINE_REPLAY_VERSION bump gate.
#
# Rationale for each exclusion:
#   - A change to these files does NOT affect chess-rule semantics (move
#     legality, draw rules, canonical state hash, mod-specific rules).
#   - Therefore they do NOT require a manual ENGINE_REPLAY_VERSION bump.
#
# Format: one path per line, relative to frontend/native/engine/.
# Blank lines and lines beginning with '#' are ignored.
#
# To add a new file: add it here AND justify the exclusion with a comment.
# To WATCH a new file: add it to .github/workflows/engine-replay-version-bump-required.yml
