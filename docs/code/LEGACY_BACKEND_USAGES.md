# Legacy Backend Usages — Freeze Inventory

> **Roadmap:** Phase 0 §0.1.bullet-1  
> **Status:** Frozen.  No new file in `frontend/lib/**` may import a symbol from
> any of the four legacy service files listed below.

## Four legacy service files (the "freeze set")

| File | Purpose |
|---|---|
| api_service.dart | HTTP client for the Go backend REST API |
| game_websocket.dart | WebSocket client for real-time game updates |
| saved_game.dart | `SavedGame` model (JSON serialisation) |
| saved_games_service.dart | Local-file saved-games store (JSON-on-disk) |

---

## Current call sites (allowed to import at freeze time)

These files existed **before** the freeze and are permitted to retain their
legacy imports until they are migrated in Phase 0.2.

| File | Imported legacy symbol(s) | Purpose |
|---|---|---|
| `frontend/lib/analytics/custom/custom_board_setup.dart` | `ApiService` | Sends custom board positions to the Go backend for analysis |
| `frontend/lib/management/online_controller.dart` | `ApiService`, `GameWebSocket` | Manages online game sessions: creates game via API, receives moves via WebSocket |
| `frontend/lib/management/watch_engine_controller.dart` | `SavedGame`, `SavedGamesService` | Persists completed games to local storage after engine play |
| `frontend/lib/services/saved_games_local.dart` | `SavedGame` | SQLite-backed replacement store; shares the `SavedGame` model with the legacy service |
| `frontend/lib/services/saved_games_service.dart` | `SavedGame` | Owns the `SavedGame` model; persistence is local-file based |
| `frontend/lib/ui/online_bot_vs_bot_page.dart` | `ApiService` | Creates and manages bot-vs-bot games on the Go backend |
| `frontend/lib/ui/saved_games.dart` | `SavedGame`, `SavedGamesService` | Lists and manages saved game history |
| `frontend/lib/main.dart` | `SavedGamesService` | Registers `SavedGamesService` as a singleton on app start |

---

## Migration plan

All call sites above are migrated in Phase 0.2 when `kUseLegacyBackend` is set
to `false` (the default).  After migration, each file will import
`SavedGamesLocal` (the SQLite-backed replacement) instead of the legacy service.
The HTTP / WebSocket paths (`ApiService`, `GameWebSocket`) are deprecated and
will be dead-code-eliminated once the Phase 3 signaling server is live.
